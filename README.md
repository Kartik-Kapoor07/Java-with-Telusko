# Java with Telusko ☕

A structured repository documenting my journey of learning **Java** through the Telusko Java course.

This repository contains practice programs, experiments, and projects as I build a strong foundation in Java.

## 🎯 Learning Goals

* Learn Java fundamentals
* Understand Java syntax and programming concepts
* Develop a strong understanding of Object-Oriented Programming
* Practice writing clean and structured Java code
* Build small projects to apply what I learn
* Become comfortable with Java before starting DSA

> **Note:** DSA is intentionally not included in this repository. I will study DSA separately after completing my Java fundamentals.

For each topic, I aim to:

1. Learn the concept from the course.

5. Document important concepts and mistakes.
6. Apply the knowledge through projects.
